# Release Notes - Version 1.1.1

This release introduces new customization sliders, a layout overhaul for the config GUI, and a reset option.

## Features & Enhancements
- **Adjustable Particle Sizes**: Added a slider to scale particle sizes from `0.5x` to `2.0x`.
- **Adjustable Color Saturation**: Added a slider to scale blood particle color saturation from `0.0x` (fully grayscale) to `2.0x` (vivid/saturated).
- **Reset to Defaults**: Added a "Reset" button to instantly restore default config options.
- **GUI Layout Overhaul**: Structured settings widgets into a 2-column grid layout to prevent text/button cutoff on lower screen resolutions. Shortened GUI labels for a cleaner fit.

## Platform Compatibility
This release compiles and runs on:
- **Minecraft 1.21.4 (26.2)** (Fabric & NeoForge)
- **Minecraft 1.21.2 - 1.21.3 (26.1)** (Fabric & NeoForge)
- **Minecraft 1.20.5 - 1.21.1 (1.21)** (Fabric & NeoForge)
